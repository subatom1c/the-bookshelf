# the-bookshelf
Simple self-hosted digital bookshelf for reading PDF's for any device.

# Features
```text
- Reading without downloading
- Self Host anywhere
- Works on desktop and mobile
```

# Tech Stack
```text
- HTML
- JS
- Flask (Python) for backend
```

# Structure
```text
the-bookshelf/
├── books/
├── css/
├── covers/
├── index.html
└── README.md
```

# Dependencies
To get book covers
```text
python3 -m venv venv
source venv/bin/activate
pip install pymupdf
pip install flask
```
